구조 원칙 5
⓪ 브랜드 홈이 상위 — 어린왕자 홈 = 세계의 집. 어린왕자 플레이북(본편)·셀럽 보이스 플레이북·굿즈는 그 안에 진열되는 상품. 뷰어에 상점이 붙은 서비스가 아님. 홈 표현은 웹 기술이 담당, 플레이북 엔진은 책을 펼칠 때만.
① 입구가 곧 데모 — 랜딩은 브랜드 데스티네이션. 세계와 상품군이 보이고, "모자를 당겨보세요" 플레이어블이 훅 (정적 히어로 금지).
② 홈은 별자리 서재 — 단일 작품 서비스이므로 작품 페이지가 아닌 "내 하늘(수집 상태)"이 재방문의 중심.
③ 뷰어는 몰입 전용 — 풀스크린, GNB 없음, 나가기만 존재.
④ 상점은 맥락 진입 — 서재의 미해금 별·뷰어의 캡슐 터치에서 구매 시트가 뜨는 게 기본, 독립 상점은 보조.

3. 핵심 플로우 5

F1 첫 방문 → 전환  랜딩 데모(모자 당기기) → "계속 읽기" → 테마 1 감상 (게스트 허용 시) → 첫 보이스 캡슐 조우 → 가입 유도 — 데모→본편 이음새가 서비스 첫인상의 전부
F2 보이스 플레이북 구매 (핵심 BM)  뷰어 명대사 터치 or 셀럽 별 방문 → 턴테이블 UI + 미리듣기(각인) → 단권 해금 인라인 시트(이탈 없음) → 크레딧(별) 차감 또는 국내 PG/Paddle → 즉시 재생. 이후 문장을 들을 때마다 별 점등 — 결제는 한 번, 별자리 완성의 재미는 지속 — 수집 = 연출, 과금 = 단순
F3 수집 완성  서재 → 미완성 별자리 확인 → 미해금 별 미리듣기 → 잔여 문장 묶음 구매 → 별자리 연결 연출 + 공유 카드 생성
F4 공유 → 유입 (바이럴 루프)  공유 카드/링크 → /s/{sentence} 랜딩(미리듣기) → 데모 → 가입 — 이 경로만 SSR·OG 최적화 필수
F5 복귀 (리텐션)  재방문 → /library 내 하늘 → 이어보기 · 내 별 읽어주기 모드(BGM + 셀럽 낭독 자동 재생 — 매일 트는 라디오) · "여우의 시간" 훅 — 상세는 ScreenSpec에서

4. 기술 요구사항 웹팀 7/27 착수용 — 1장 요약

PWA · 라우팅

  • PWA: 설치 배너 + 오프라인 셸 (셸만 — 콘텐츠 오프라인 캐시는 스코프 외)
  • i18n: 경로 프리픽스 /{lang}/ 5로케일(간체·번체 분리) — 음성은 4벌(보통화 공용), SEO·공유 링크 언어 보존
  • SSR 범위: /s/{sentence}·랜딩만 — 나머지는 CSR(앱 성격)
  • /k/{token} 네임스페이스 예약 — 라우터에 stub만

상태 · 데이터

  • 게스트 진행+선택 데이터 로컬 저장 → 가입 시 병합 — 별 속성 포함, F1 전환의 전제
  • 소유권 판정: 테마 단위 + 문장 단위(SKU) 이중 — 코인게이트 확장, 캐싱 필수
  • 이어보기: 테마·씬 좌표 서버 저장
  • 서재 = 소유권 + 플레이 데이터 합성 뷰 — 선택·분기 결과가 별 속성 생성(개인화)
  • 플레이 선택 이벤트 계정 저장 — L3 계정 변수·서버 fallback(스펙 확정) 기반

결제 · 오디오

  • 결제 2채널: 국내 PG + Paddle 오버레이 체크아웃 — 결제 후 복귀 딥링크, F2 인라인 시트의 전제
  • 크레딧(별) 지갑: 국내 자사 캐시(단일 가맹점 면제 트랙) + 글로벌 Paddle 번들 충전 — 국가별 가용성 플래그(v1.0 한국만 ON), 무상 포인트는 전 지역 공통
  • 오디오 보호 전송: 캡슐(셀럽 진성) 최고 등급 — 서명 URL·구간 스트리밍
  • 나레이션 120분 × 4개국어 구간 로딩
  • 미리듣기: 초반 2~3초 별도 저용량 에셋 — 원본 노출 없음

뷰어 통합

  • 플레이북 출력물 임베드 인터페이스 — 킥오프 주간(8/18~) 플레이북엔진팀 합동 점검
  • 뷰어 → 웹 이벤트 브리지: 캡슐 터치·씬 도달·테마 완료·선택/분기 결과 — 구매 시트·서재 갱신·별 생성 트리거
  • 웹 → 뷰어: 소유권 상태 주입 (재생 가능 문장 목록)
  • 읽어주기 모드 = 웹 스코프 — 오디오 연속 재생+텍스트·삽화, 플레이북 엔진 불요. 뷰어와 일정 비블로킹
