3. 핵심 플로우 4 + [v2] F3 — §6 보관

F1 첫 방문 → 전환  원페이지(히어로→카운트다운→로어) → 데모 재생(모자 당기기) → "계속 읽기" → 테마 1 감상 (게스트 허용 시 — D2) → 잠금 조우 → 가입·구매 유도 — 데모→본편 이음새가 첫인상의 전부
F2 구매 (핵심 BM = 책 1권)  에디션 섹션(구성물 카드: 본편·낭독·읽어주기) → 구매 CTA → /checkout(국내 PG/Paddle, 인라인·이탈 없음) → 즉시 /read 진입. 결제는 한 번, 단순하게 — 셀럽 단권·캡슐 BM은 v2(§6)
F4 공유 → 유입 (바이럴 루프)  공유 카드/링크 → /s/{sentence} 랜딩(미리듣기) → 데모 → 구매·가입 — 이 경로만 SSR·OG 최적화 필수
F5 복귀 (리텐션)  재방문 → 원페이지 상태 전환("지금 읽을 수 있습니다") 또는 /read 이어보기 → 읽어주기 모드(BGM + 낭독 자동 재생 — 매일 트는 라디오) · 테마 순차 오픈 알림 훅 — 상세는 ScreenSpec
[v2] F3 수집 완성  서재 → 별자리 → 캡슐 묶음 구매 → 연결 연출 — §6 보관

4. 기술 요구사항 웹팀 7/27 착수용 — 1장 요약

PWA · 라우팅

  • 모바일 반응형 필수 — 대외 시연 대응(킥오프 40:41, 원칙 ②)
  • PWA: 설치 배너 + 오프라인 셸 (셸만 — 콘텐츠 오프라인 캐시는 스코프 외)
  • i18n: 경로 프리픽스 /{lang}/ 5로케일(간체·번체 분리) — 음성은 4벌(보통화 공용), SEO·공유 링크 언어 보존
  • SSR 범위: /s/{sentence}·랜딩만 — 나머지는 CSR(앱 성격)
  • /k/{token} 네임스페이스 예약 — 라우터에 stub만

상태 · 데이터

  • 게스트 진행+선택 데이터 로컬 저장 → 가입 시 병합 — 별 속성 포함, F1 전환의 전제
  • 소유권 판정: 테마 단위 기본, 문장 단위(SKU)는 스키마만 예약 — 코인게이트 확장, 캐싱 필수. v1.0 SKU = 책 1권
  • 이어보기: 테마·씬 좌표 서버 저장
  • 플레이 선택 이벤트 수집 = v1.0 필수 — L3 계정 변수·서버 fallback 기반. P-06(별 생성)은 v2 동결이나 수집 스키마는 P-05(9/4)로 흡수: 지금 쌓아야 v2 별 생성 재료가 존재. 서재 합성 뷰는 §6

결제 · 오디오

  • 결제 2채널: 국내 PG + Paddle 오버레이 체크아웃 — 결제 후 복귀 딥링크, F2 인라인 결제의 전제
  • 크레딧(별) 지갑 — v2 동결(§6). v1.0은 단건 결제만, 지갑 스키마는 자산 보존
  • 오디오 보호 전송: 본편 낭독 — 서명 URL·구간 스트리밍. 캡슐(셀럽 진성) 최고 등급 보호는 v2 §6
  • 나레이션 120분 × 4개국어 구간 로딩
  • 미리듣기: 초반 2~3초 별도 저용량 에셋 — 원본 노출 없음

뷰어 통합

  • 플레이북 출력물 임베드 인터페이스 — 킥오프 주간(8/18~) 플레이북엔진팀 합동 점검

  • 웹 → 뷰어: 소유권 상태 주입 (재생 가능 문장 목록)
  • 읽어주기 모드 = 웹 스코프 — 오디오 연속 재생+텍스트·삽화, 플레이북 엔진 불요. 뷰어와 일정 비블로킹
